# AIEN on GitHub

This repository holds the [AienOS organization profile](profile/README.md) and default GitHub community guidance. It is not the operating-system source tree.

**Start with the project:** [AienOS front door](https://github.com/aien-dev/aienix) · [source-linked teaching tracker](https://github.com/aien-dev/aienix/issues/9) · [current work](https://www.aienos.com/now/)

## Native GitHub features in this repository

| File | Where GitHub uses it |
| --- | --- |
| [profile/README.md](profile/README.md) | The public organization overview, with actual project artwork, evidence and existing tag/release links. |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Default contribution guidance for organization repositories without their own corresponding file. |
| [SUPPORT.md](SUPPORT.md) | Reproduction and help routes, without promising a support contract. |
| [SECURITY.md](SECURITY.md) | The existing security-reporting policy. |
| [Reproduction form](.github/ISSUE_TEMPLATE/01-reproduction.yml) | Structured exact-source, environment, expected/observed-result reports. |
| [Issue chooser](.github/ISSUE_TEMPLATE/config.yml) | Learning, contribution and security routes; blank issues remain available. |
| [Pull request template](.github/PULL_REQUEST_TEMPLATE.md) | The existing review and verification checklist. |
| [Brand provenance](profile/BRAND_PROVENANCE.md) | Exact input image, reproducible preview/crop commands and observed GitHub setting readbacks. |

> [!NOTE]
> Repository-specific community files take precedence. If a repository supplies its own issue-template configuration, GitHub does not combine it with these organization defaults. These files do not enable disabled issue trackers, grant private access, change branch protection or create a shared software licence.

The profile's tags and release links point to existing records. Published prereleases, historical experiment tags and current qualification are distinct; this presentation does not manufacture a release, a passing badge or project maturity.
