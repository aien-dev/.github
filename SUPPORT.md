# Help and reproduction reports

Start at the [AienOS front door](https://github.com/aien-dev/aienix) to choose a component, then use that repository's source-linked walkthrough and existing issue tracker.

For a reproduction problem, include:

- Exact repository URL, source commit and dependency pins.
- Operating system, architecture and toolchain versions.
- The smallest command/input that demonstrates the problem.
- Expected output, actual output and exit status.
- Whether this was a host fixture, simulator, emulator or physical hardware run.
- Which prerequisites or downloads were unavailable.

Search for an existing report first. Remove credentials and personal data from logs. Do not post private repository names or artifacts to a public issue. A failed tutorial is useful evidence; please report it rather than changing the expected result.

There is no implied response-time guarantee or production support contract. Pre-alpha software and historical examples have explicit limits. For security-sensitive reports, read [SECURITY.md](SECURITY.md) instead of opening a public debugging issue.
